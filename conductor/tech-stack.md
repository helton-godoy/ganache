# Tech Stack

This document outlines the core technologies and frameworks utilized in the project.

## Programming Languages
*   **TypeScript:** Used for the frontend development, leveraging its static typing for robust and maintainable code.
*   **Rust:** Employed for the backend services, chosen for its performance, safety, and concurrency features.

## Frontend Frameworks
*   **Next.js:** The React framework for building performant and scalable web applications, providing features like server-side rendering and routing.
*   **React:** A JavaScript library for building user interfaces, forming the foundation of the frontend.
*   **Tailwind CSS:** A utility-first CSS framework for rapidly building custom designs.
*   **Shadcn UI:** A collection of reusable components built with Radix UI and Tailwind CSS, providing accessible and customizable UI primitives.

## Backend Frameworks
*   **Axum:** A web application framework for Rust, known for its ergonomics and performance.
*   **Tokio:** An asynchronous runtime for Rust, enabling non-blocking I/O and concurrent programming.

## API
*   **OpenAPI / REST:** The project utilizes a RESTful API approach, documented with OpenAPI for clear communication between frontend and backend.

## Database/Storage Related
*   **ZFS:** A powerful file system and logical volume manager, providing data integrity, snapshots, and replication.
*   **DRBD:** (Distributed Replicated Block Device) A software-based, shared-nothing, replicated storage solution that mirrors the content of block devices between hosts.
